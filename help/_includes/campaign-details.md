# キャンペーンの詳細

キャンペーンの詳細は、マーケティングキャンペーンの基本特性を定義します。 これらの詳細は、キャンペーンブリーフに含まれる定義の特徴と類似しています。

キャンペーン _詳細_ フィールドは、次の表で定義されています。

| 詳細 | 説明 |
|------------|-------------|
| キャンペーン名 | キャンペーンの識別に使用される一意の名前。 この名前は、製品全体でキャンペーンラベルとして使用できます。 |
| 説明 | 社内関係者に対する施策の概要。 |
| 目的 | ブランド認知度の向上、リードの創出、売上の増加など、キャンペーンのプライマリ目標。 |
| 重要なメッセージ | すべてのキャンペーンアセットで伝える一元的なメッセージを定義します。<br> キャンペーンの戦略的メッセージとトーンにコンテンツ制作者を集中させる。 |
| 開始 | 広告体験がアクティブになる四半期、シーズン、年。 |
| 終了 | 広告体験が終了する四半期、シーズン、年。 |
| ステータス | 今後のキャンペーン開始<br> アクティブ – キャンペーンは進行中<br>完了 – キャンペーン終了 |
| 最終変更日 | （読み取り専用）最後にキャンペーンの詳細またはコンテンツが編集された時刻を識別するタイムスタンプ。 |
