# GenStudio for Performance Marketing スニペット

## インサイトの接続 {#connect-insights}

>[!TIP]
>
>GenStudio for Performance Marketingでは、データの受信を開始するには、チャネルアカウントに接続する必要があります。 [有料メディアアカウントの接続](/help/user-guide/connectors/connect-channel.md)を参照してください。

## CSS効果に関する注意 {#note-css-effects}

>[!NOTE]
>
>GenStudio for Performance Marketingは、`backdrop-filter` フィルターエフェクト（ぼかし、明るさ、コントラスト）などの特定のCSS グラフィカルエフェクトをサポートしていません。 テンプレートがこれらのプロパティを使用している場合、書き出されたコンテンツに期待どおりに表示されない可能性があります。

## メモ AEM Assets {#note-aem-assets}

>[!INFO]
>
>[!DNL AEM Assets Content Hub] リポジトリからのアセットの表示または操作で問題が発生した場合は、システム管理者に問い合わせて、正しい組織または製品プロファイルにアクセスできることを確認してください。 [&#x200B; リポジトリ  [!DNL AEM Assets Content Hub] に接続](/help/user-guide/content/connect-aem-repo.md)を参照してください。

## 表のフィルタリングのヒント {#filter-table}

>[!TIP]
>
>検索結果が多すぎるか、`No results found`件のメッセージが表示されていますか？ 選択範囲を変更したり、すべてのフィルターをクリアしたり、日付範囲を調整したりして、フィルターを調整します。 動的で汎用性の高いフィルター機能について詳しくは、[&#x200B; インサイトビューのフィルター](/help/user-guide/insights/filter-views.md)を参照してください。
