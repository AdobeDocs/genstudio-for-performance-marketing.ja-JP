# Adobe GenStudio for Performance Marketing のアクティブ化

GenStudio for Performance Marketing [!DNL Activate] は、特定の有料広告チャネルへのアクティベーションに向けて広告エクスペリエンスを準備するための一元的な場所を提供します。 _アクティベーション_&#x200B;とは、特定の有料チャネルへのプレースメントに合わせて独自にカスタマイズされたクリエイティブな広告エクスペリエンスとして、広告エクスペリエンス、アセット、テキストを準備するプロセスのことです。 アクティベーションはクリエイティブなエクスペリエンスを指定されたチャネルへ非アクティブな状態で配信し、チャネルから最終的なレビューとデプロイメントの準備が整います。 これにより、広告エクスペリエンスを意図したマーケットに配信できます。

コンテンツ編集者やシステムマネージャーは、GenStudio for Performance Marketing 内で生成またはアップロードされたアセットを含むエクスペリエンスを公開できます。

[!DNL Activate] は、サポートされている各有料メディアチャネルの製品カードを表示します。 このタイルには、有料メディアチャネルを特定し、過去 30 日間に発生した広告アクティベーションの成功数が一覧表示されます。 また、アクティベーションの管理や、新しいアクティベーションの作成を行うためのエントリポイントも示されます。

広告エクスペリエンスをアクティブ化するには、各有料メディアチャネルのアカウントを GenStudio for Performance Marketing に接続する必要があります。

## Activate のユースケース

* 特定の有料広告チャネル向けに、承認済みエクスペリエンスを [!DNL Content] から直接アクティブ化します。

* [アクティベーションを作成します](create-activation.md)。 ビジュアルアセットの選択、テキストの割り当て、メタデータの定義を行って広告エクスペリエンスを作成し、有料チャネルに配信できます。

* [アクティベーションを管理します](manage-activations.md)。 _[!DNL Activate]_は、アクティブ化されたすべてのエクスペリエンスの概要を示します。 また、個々のアクティベーションの詳細を表示することもできます。

## Activate の機能

[!DNL Activate] は、ターゲットにする有料チャネルへ配信するための広告エクスペリエンスの準備を容易にします。

### 承認済みのエクスペリエンスを Content から直接アクティブ化

[!DNL Content] から直接、承認済みのエクスペリエンスをアクティブ化したり、特定の有料チャネル向けに、承認済みの複数のエクスペリエンスをアクティベーショングループとしてアクティブ化したりできます。 グループ内のすべてのエクスペリエンスは、同じ有料チャネルをターゲットにする必要があります。

### アクティベーション用のエクスペリエンスを準備

_エクスペリエンス設定_&#x200B;ページには、広告エクスペリエンスのビジュアル要素の選択、広告テキスト（コールトゥアクションテキストを含む）の調整、エクスペリエンスのトラッキングや可視性を強化する有用なメタデータの追加に必要なツールが統合されています。

### 広告エクスペリエンス用のアセットを選択

[!DNL Content] から承認済みのビジュアルアセットを検索および選択するか、Dropbox または OneDrive からアセットをアップロードします。 デバイスからアセットを直接アップロードできます。 1 つの広告エクスペリエンスを複数のプレースメントで配信できます。 広告のプレースメントに必要な縦横比で、アセットをアップロードできます。

### エクスペリエンスをプレビューし、広告チャネルにアクティブ化

この広告アクティベーションに関連する有料チャネルのアカウント、広告セット、Meta キャンペーンを確認します。 _プレビュー_&#x200B;パネルでは、広告を確定する前に、様々なプレースメントでの広告エクスペリエンスを表示できます （_プレビュー_&#x200B;パネルでプレースメントを選択すると、影響を受けるのは広告の表示のみです。 _プレビュー_&#x200B;パネルでのプレースメントの選択は保存されません）。 広告エクスペリエンスに問題がなければ、「**[!UICONTROL 公開]**」をクリックして、エクスペリエンスと関連するメタデータを有料広告チャネルにプッシュします。
