# アクティベーションワークフロー

[!DNL Activate]は、有料広告プラットフォームに公開されたエクスペリエンスをアクティブ化します。 GenStudio for Performance Marketingエクスペリエンスとは、広告などのマーケティングキャンペーンコンポーネントのことで、有料広告プラットフォーム上の特定のオーディエンスを対象として準備されます。 アクティベーション向けのエクスペリエンスは、次の3つの主要な要素で構成されています。

* **メディアアセット**：広告エクスペリエンス内の、プラットフォームや形式によって異なるファイルタイプと縦横比の画像またはビデオ。

* **テキスト**：見出し、本文、call-to-action要素など、広告に含まれるすべての形式のコピー。

* **メタデータ**: パフォーマンス分析、フィルタリング、トラッキングを強化する、ユーザー定義の属性（通常、広告オーディエンスには表示されません）。

これらのコンポーネントは、アクティブ化の前に[!DNL Content]で準備して承認します。 [!DNL Activate]は、承認済みのアセット、見出し、本文の作成や編集を行っていません。 各プラットフォームが必要とする設定のみを適用し、エクスペリエンスを公開します。

単一のアクティベーションテーブルには、複数の有料広告プラットフォームと広告フォーマットのエクスペリエンスを含めることができます。

>[!VIDEO](https://video.tv.adobe.com/v/3503539?captions=jpn&learn=on)

## プラットフォームアカウントの接続

エクスペリエンスをそのプラットフォームにアクティベートするには、GenStudioのシステムマネージャーまたはエディターが各有料広告プラットフォームの広告アカウントを接続する必要があります。 このプロセスの手順については、[有料メディアアカウントの接続](/help/user-guide/connectors/connect-channel.md)を参照してください。

## アクティベーションを開始

次の2つのエントリポイントのいずれかからアクティベーションを開始します。

* **[!DNL Content]**&#x200B;から：エクスペリエンスにフィルターを適用して、1つ以上の公開されたエクスペリエンスを選択し、上部のアクションバーで「**[!UICONTROL アクティブ化]**」をクリックします。

  ![&#x200B; コンテンツで公開されたエクスペリエンスを選択し、「アクティブ化」をクリックしてアクティブ化を開始する](./images/content-select-activate.png)

* **[!DNL Activate]**&#x200B;から：[!DNL Activate] ランディングページで、**[!UICONTROL 以上の新規アクティブ化]**&#x200B;をクリックします。 同じエクスペリエンスギャラリーが開き、アクティベーションするエクスペリエンスを選択します。

いずれの場合も、エクスペリエンス名で検索するか、複数のチャネルでフィルタリングして、目的のエクスペリエンスを見つけることができます。

表示形式のエクスペリエンスが含まれる場合は、使用するディスプレイプラットフォームを指定します。Google Campaign Manager 360、Innovid、Amazon Ads、またはThe Trade Deskです。 次に、**[!UICONTROL 開始アクティベーション]**&#x200B;をクリックします。 Meta、LinkedIn、TikTok、YouTube、ChatGPTなどの他の形式では、[!DNL Activate]はエクスペリエンスのチャネルからプラットフォームを推測し、このステップをスキップします。

次に、[!DNL Activate]は、選択したすべてのエクスペリエンスを一覧表示するアクティブ化テーブルを生成します。

![新しく生成されたアクティベーションテーブルをMetaとLinkedInのサブテーブルにグループ化し、すべての広告に「フィールドが完了するまで注意が必要」とフラグ付けしました](./images/activation-table.png)

[!DNL Activate]は、広告のフォーマットとプラットフォームによってテーブルをサブテーブルに整理します。例えば、Metaのシングル画像やLinkedInのシングル画像などです。 各行は1つの広告を表します。 LinkedIn、TikTok、ディスプレイプラットフォームなどの多くのプラットフォームでは、複数の縦横比を使用したエクスペリエンスでは、縦横比ごとに1行が生成されます。必要のない行は削除します。 Metaは例外です。 Meta広告では、1つの広告内に複数のアスペクト比を含めることができるため、複数のアスペクト比のMeta体験では、1行のみを生成します。

## アクティベーションテーブルの管理

アクティベーションテーブルは、開くと自動的にドラフトとして保存されます。 公開前にいつでもドラフトを残して再開できます。

既に開いているアクティベーションテーブルにエクスペリエンスをさらに追加するには、テーブルの右上にある「**[!UICONTROL エクスペリエンスを追加]**」をクリックします。 これにより、エクスペリエンスギャラリーが再度開き、[!DNL Activate]が既存のテーブルに追加する追加のエクスペリエンスを選択できるようになります。

**[!UICONTROL さらにエクスペリエンスを追加]**&#x200B;すると、同じテーブル内の複数の表示プラットフォームに対してもアクティブ化できます。 表示形式のエクスペリエンスでは、最初に単一の表示プラットフォームを選択するように求められますが、**[!UICONTROL 複数のエクスペリエンスを追加]**&#x200B;をクリックし、複数の表示形式のエクスペリエンスを選択し、テーブルに既に表示されている表示プラットフォームとは別の表示プラットフォームを選択できます。 例えば、Innovid広告が既に含まれているテーブルにThe Trade Desk広告を追加できます。

テーブルに適切なエクスペリエンスを設定したら、次に各広告のフィールドを設定します。

## 広告とプラットフォームの設定の詳細

行ごとにフィールドをインラインで編集するか、同じ形式テーブル内の複数の行を選択し、表示されるツールバーの&#x200B;**[!UICONTROL 詳細を編集]**&#x200B;をクリックして、それらのフィールドを一度に一括編集します。

![&#x200B; アクティベーションテーブルで複数の広告を選択して、詳細またはプラットフォーム設定を一括編集する](./images/bulk-edit-action-bar.png)

承認されたアセット、見出し、本文のコピーはロックされており、[!DNL Content]でレビューと承認が既に行われているため、アクティベーションテーブルで編集できません。 残りのフィールドは編集でき、プラットフォームによって異なります。 [!DNL Activate]には、選択したプラットフォームと形式に関連する列のみが表示されます。 プラットフォームごとに編集可能な内容の参考資料として、次の表を使用してください。

**プラットフォーム別の編集可能なフィールド**

| プラットフォーム | サポートされている形式 | ロックされたコピー | 編集可能なテキストフィールド | プラットフォーム設定フィールドの編集 |
|---|---|---|---|---|
| Meta | 画像、動画、カルーセル | Headline, Body | 説明、Call-to-action、宛先URL、URL パラメーター、トラッキング ID | 広告アカウント，Facebook ページ，Instagram プロフィール，Metaキャンペーン，Meta広告セット |
| LinkedIn | 単一の画像、単一ビデオ | Headline, Introductory Text | 説明、Call-to-action、宛先URL、URL パラメーター、トラッキング ID | 広告アカウント、キャンペーン、広告セット |
| Google Campaign Manager 360 | 静的ディスプレイ、ビデオディスプレイ、HTML5 Zip ディスプレイ | n/a | トラッキング ID | 広告主 |
| Amazon Ads | 静的表示 | n/a | トラッキング ID | アカウント |
| Innovid | 静的な表示、HTML5 Zip表示 | n/a | トラッキング ID | Account, Creative Library, Concept Name |
| TikTok | インフィード動画広告 | プライマリ | Call-to-action、宛先URL、トラッキング ID | 広告アカウント、キャンペーン、広告グループ |
| YouTube | Google Ads デマンドジェネレーションキャンペーンのShorts | 説明 | Call-to-action、ビジネス名、宛先URL、URL パラメーター、トラッキング ID | アカウント、キャンペーン、広告グループ、ロゴ |
| ChatGPT | チャットカード | タイトル、本文 | ターゲット URL、トラッキング ID | OpenAI広告アカウント，OpenAI キャンペーン，OpenAI広告グループ |
| The Trade Desk | 静的表示 | n/a | トラッキング ID | アカウント，キャンペーン |

広告フォーマットのグループに対してプラットフォーム設定フィールドを設定するには、**[!UICONTROL プラットフォーム設定の管理]**&#x200B;をクリックし、結果のダイアログでフィールドを編集します。

![Meta広告アカウント、キャンペーン、広告セットを選択するためのプラットフォーム設定を管理ダイアログ &#x200B;](./images/manage-platform-settings.png)

「**[!UICONTROL トラッキング ID]**」フィールドは最初は空白です。 トラッキング IDは、広告プラットフォームの広告名またはクリエイティブ名と同じもので、広告プラットフォームはそれを広告の識別名として使用します。 このフィールドを使用して、レポートとトラブルシューティング用の広告を特定します。 「**[!UICONTROL トラッキング ID]**」フィールドに使用する値を入力します。

![&#x200B; アクティベーションテーブルのトラッキング ID フィールドをインラインで編集する](./images/tracking-id-edit.png)

**[!UICONTROL トラッキング ID]** フィールド間をより迅速に移動するには、次のキーボードショートカットを使用します。

* **Enter**&#x200B;を押して、選択した&#x200B;**[!UICONTROL トラッキング ID]**&#x200B;の編集フィールドを開きます。
* **上**&#x200B;または&#x200B;**下**&#x200B;矢印キーを押して、その列の前または次の&#x200B;**[!UICONTROL トラッキング ID]** フィールドに移動します。
* **Enter**&#x200B;をもう一度押して、編集を保存します。

## エクスペリエンスのレビューと広告プラットフォームへの公開

すべての行に[!UICONTROL &#x200B; アクティベートの準備完了]が表示されていることを確認します。 [!DNL Activate]は、フィールドが見つからないか無効であり、互換性のないCTAが含まれており、トラッキング IDが[!UICONTROL 要注意]として重複していることを示しています。 すべての行の準備ができたら、**[!UICONTROL プラットフォームに送信]**&#x200B;をクリックし、公開ダイアログで確認します。

![すべての行にアクティベーションの準備完了が表示されるアクティベーションテーブル。プラットフォームへの送信を有効にします](./images/ready-to-activate.png)

[!DNL Activate]は、各広告のステータスをほぼリアルタイムでレポートします。保留中、次にプラットフォームに送信、または失敗しました。 広告が失敗した場合は、そのステータスにカーソルを合わせると、プラットフォームのエラーが表示されます。 テーブル内の失敗したすべての広告を、個別に再試行するのではなく、**[!UICONTROL 再試行]**&#x200B;をクリックして、一度に再試行できます。 プラットフォームに送信済みの行は再送信からロックされ、宛先プラットフォームのネイティブ広告マネージャーに広告へのディープリンクが含まれます。 最後の公開前レビューと広告の開始は、宛先プラットフォームの独自の広告マネージャーで行われます：[!DNL Activate]は、常に非アクティブ状態で広告を配信します。

![公開後の「保留中」と「送信済み」のステータスの組み合わせを示すアクティベーションテーブル &#x200B;](./images/activation-status-pending.png)

アクティブ化テーブルが[!DNL Activate] ランディングページに表示されます。
