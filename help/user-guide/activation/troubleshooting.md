# アクティベーションの最適化

有料広告チャネルの広告体験をアクティベートするには、主にふたつのフェーズがあります。

* エクスペリエンスをアクティベーションするための準備

* 指定の有料チャネル広告マネージャーにエクスペリエンスを公開する

広告エクスペリエンスを作成およびアクティベートする際のベストプラクティスに従うことで、ターゲットチャネルへの配信時に発生する可能性のある複雑化やエラーを最小限に抑えることができます。

## ベストプラクティス

ここでは、一般的なベストプラクティスとそれらを防ぐエラーをいくつか紹介します。

* **有効で完全な宛先URLを使用**

  無効なURLはエラーをトリガーする可能性があります。 エラーの例：_入力されたURLがWeb サイトに直接送信されていません。 有効なURLを入力して、もう一度試してください。 (100)_

* **アプリケーションでトークンの有効期限が正しく処理されていることを確認してください**

  アプリケーションは、必要に応じて新しいトークンをリクエストする必要があります。 必要に応じて、再認証を行い、再度ログインするかセッションを更新して、新しいアクセストークンを取得します。 サンプルエラー：_アクセストークンの検証中にエラーが発生しました。ユーザーがパスワードを変更したか、セキュリティ上の理由からFacebookがセッションを変更したため、セッションは無効化されました。 (190)_

* **広告セットを確認し、常に1つの広告のみがアクティブであることを確認します**

  複数のMeta広告をアクティベートする必要がある場合は、それぞれに個別のダイナミックCreative広告セットを作成します。 サンプルエラー：_動的Creative広告セットでは、最大1つのアクティブ広告が許可されます。 同じDynamic Creative広告セットの下に複数の広告を作成することはできません。 (100)_

* **適用されたルールの数を、プラットフォームで指定された金額と一致させます**

  ペイドチャネルでは、適用されるルールの数が、指定された形式に一致することを期待しています。  必要に応じて、プラットフォームが指定する値に一致するようにルールの数を調整します。 サンプルエラー：_Ad AssetFeedには、形式：形式の名前に対するX ターゲットルールがありますが、この形式に対するX ターゲットルールが正確に必要です。 (100)_

* **広告セットの目標と互換性のあるcall-to-action （CTA）を選択してください**

  Dynamic Creative広告セットトリガーの目的と互換性のないコールトゥアクションがエラーです。 サンプルエラー：_call to actionの種類Xは、Dynamic Creative広告セットの目標Yではサポートされていません。 (100)_

* **ターゲット広告セットのキャップが広告エクスペリエンスの数をサポートしていることを確認する**

  ターゲット広告セットの広告制限が、アクティベートされた広告体験に対応できることを確認します。 必要に応じて、広告セットから不要または非アクティブな広告を削除し、この制限内に収まるようにします。 または、新しい広告セットを作成して追加の広告をアクティベートします。 サンプルエラー：_広告アカウントあたりのキャンペーン、広告セットまたは広告制限に達しました。 各広告セットには、最大50個の広告を含めることができます。 これには、一時停止/非アクティブ/オフの広告が含まれます。 (100)_

* **選択したCTAの種類**&#x200B;をサポートしていることを確認してください

  エクスペリエンスにサポートされているCTA タイプが含まれていることを確認します。 サンプルエラー：_（#100）無効なcall to actionの種類（100）_
