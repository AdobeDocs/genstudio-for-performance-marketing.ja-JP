# GenStudio for Performance Marketing [!DNL Products]

GenStudio for Performance Marketingの[!DNL Products]は、製品の仕様、利点、差別化要因に関する詳細な理解を活用して、インパクトのあるコンテンツを生成しています。

[!DNL Products]には、画像、説明、価値提案など、特定の製品のすべての要素が含まれており、統一感のあるブランド表現を作成します。 Adobeの高度なAI テクノロジーであるGenStudio for Performance Marketing [guidelines](/help/user-guide/guidelines/overview.md)を活用して、製品の強みを示し、あらゆるメッセージの一貫性を確保する魅力的なコンテンツを生成します。

**製品を表示または変更するには**:

1. 左側のナビゲーション領域で、**[!UICONTROL 製品]**&#x200B;をクリックします。
1. [個々の詳細を表示するか、製品](add-guidelines.md#manage-products)を変更するには、_[!DNL Products]_アクションメニューをクリックし、**[!UICONTROL 開く]**を選択します。
1. 「ガイドライン」カテゴリのテキストフィールドをクリックして、製品ガイドラインを修正します。

GenStudio for Performance Marketingで商品を追加または変更する方法については、[ ガイドラインの追加](add-guidelines.md)を参照してください。

## [!DNL Products]件のガイドライン

GenStudio for Performance Marketingでは、個々の商品ガイドラインをもとに、商品を明確に把握できます。

![製品ガイドライン ](/help/assets/products.png){width="600" zoomable="yes"}

このガイドラインでは、各ガイドラインのカテゴリと関連する例について詳しく説明します。 例は、生成されたコンテンツの出力を形成するサンプル入力です。 これらを使用して、[!DNL Products]のガイドラインに情報を提供します。

次の表は、[!DNL Products]のガイドラインの各カテゴリと関連する例を示しています。

| ガイドラインのカテゴリ | 説明 | ベストプラクティス |
| ------------------| ----------------| :---------- |
| 製品名 | 企業が顧客に提供するサービス、ソリューション、有形製品などのことです | 商品名を明確にし、商品を簡単に理解できるようにします&#x200B;<br><br>_例_:「Photoshop」（SaaS企業） <br> 「業務管理のマスター」（教育機関） <br> 「Wealth Management Plan」（金融機関） <br> 「Home Essentials Decor」（小売） |
| 説明 | 製品とその目的を強調した、簡潔明瞭な要約 | 簡潔な言葉を使って、製品を明確に説明し（1～2行の文章）、潜在的なユーザーに明確なコンテキストを提供します。 詳細な機能情報や仕様は含まれません。<br><br>_例_:「Product XYZは、タスクの整理、進捗状況の追跡、シームレスな共同作業を支援するために設計された、汎用性の高いクラウドベースのプロジェクト管理ツールです。 XYZは、小規模な企業や大企業に最適で、プロジェクトを最初から最後まで管理するためのシンプルで使いやすいインターフェイスを提供します。」 |
| 価値提案 | 問題を解決し、具体的なメリットや価値を提供する方法を説明する、明確な要約（10文未満） | 魅力的な言葉で、競合他社との差別化を重視する製品のメリットやメリットを明確に定義します。<br><br> リストの先頭に最も重要な値propを含むリスト形式で価値提案を提供します。<br><br>_例_:「XYZの価値提案：<br><li>直観的な操作でプロジェクト管理タスクを一元管理できるため、複数のツールを使用する必要がなくなります</li><li>チームの生産性が最大30%向上</li><li>お気に入りのツールとシームレスに統合し、スムーズなワークフローを実現</li><li>リアルタイムの更新とコラボレーション機能を提供し、チームの連携を維持する」</li> |
| メッセージ設定 | 特定の製品をどのようにコミュニケーションさせるべきかを示す、推奨されるコミュニケーションスタイルの明確な要約 | 明確なコミュニケーションスタイルに焦点を当てて、製品に独自のメッセージ要件を定義します。<br><br> リストで特定のメッセージ設定を指定します（各リスト項目1～2文）。<br><br> リストを合計20文以下に制限し、最も重要な情報を強調表示します。<br><br>_例_:「XYZ製品のメッセージ設定：<li>XYZ製品の最先端テクノロジーと革新的な機能をご紹介します。</li><li>この商品の手頃な価格と実用性をわかりやすく説明し、お金の価値に焦点を当てます。</li>&quot; |
