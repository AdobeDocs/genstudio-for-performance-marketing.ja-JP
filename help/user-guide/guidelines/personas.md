# GenStudio for Performance Marketing [!DNL Personas]

[!DNL Personas]は、顧客セグメントの情報、興味、課題、好み、行動特性を含め、顧客セグメントの真の姿を提供します。

GenStudio for Performance Marketingは、[&#x200B; ガイドライン &#x200B;](overview.md)の機能とAdobeの生成AI テクノロジーを活用して、ターゲット顧客向けにパーソナライズされたマーケティングコンテンツをキュレーション&#x200B;ます。

**ペルソナを表示または変更するには**:

1. 左側のナビゲーション領域で、**[!UICONTROL ペルソナ]**&#x200B;をクリックします。
1. [個々の詳細を表示するか、ペルソナ &#x200B;](add-guidelines.md#manage-personas)を変更するには、_[!DNL Personas]_&#x200B;アクションメニューをクリックし、**開く**&#x200B;を選択します。
1. ガイドラインのカテゴリテキストフィールドをクリックして、ペルソナのガイドラインを修正します。

GenStudio for Performance Marketingでペルソナを追加または変更する方法については、[Add guidelines](add-guidelines.md)を参照してください。

## [!DNL Personas]件のガイドライン

個人用ペルソナのガイドラインにより、GenStudio for Performance Marketingは[!DNL Personas]の全体像を明確に把握できます。

![&#x200B; ペルソナのガイドライン &#x200B;](/help/assets/personas.png){width="600" zoomable="yes"}

このガイドラインでは、各ガイドラインのカテゴリと関連する例について詳しく説明します。 例は、生成されたコンテンツの出力を形成するサンプル入力です。 独自の[!DNL Personas] ガイドラインを作成する際に使用します。

次の表は、[!DNL Personas]のガイドラインの各カテゴリと関連する例を示しています。

| ガイドラインのカテゴリ | ガイドラインの例 | ベストプラクティス |
| ------------------| :---------- |-------------|
| ペルソナ名 | 生成されたマーケティング資料をカスタマイズする、特定のオーディエンスセグメントを表します | 明確で簡潔なペルソナ名を追加します。<br><br>_例_:「小売のCMO」、「看護師の見込み学生」、「新しい貯蓄口座の顧客」 |
| 説明 | 主な特徴、ニーズ、行動を定義する概要 | ペルソナや独自のオーディエンスセグメンテーション（1～2行の文章）を明確に説明するために、簡潔な言葉を使います。<br><br>このオーディエンスセグメントを促進するもの（ニーズ、コア特性など）に注目する<br><br>詳細なデモグラフィックデータや追加情報を避け、説明を簡潔にします。 |
| メッセージ設定 | 特定のペルソナの共感を呼ぶ、推奨されるコミュニケーションスタイルを明確に要約 | ペルソナがどのようにコミュニケーションを受け取り、やり取りするかを重視しながら、独自のメッセージ要件とペルソナの動機を定義します。<br><br> リストで特定のメッセージ設定を指定します（各リスト項目1～2文）。<br><br> リストを合計10文以下に制限し、最も重要な情報が強調表示されるようにします。<br><br>_例_:「テクノロジーに精通したプロフェッショナル向けのメッセージ設定：<li>簡潔で専門用語を使用しないコミュニケーションを好む。</li><li>データ主導のインサイトと実用的なアドバイスにポジティブに対応。</li><li>インフォグラフィックやチャートなどのビジュアルを好み、複雑な情報をすばやく把握できます。</li><li>透明性を重視し、正直でわかりやすいアプローチを採用。</li>&quot; |
