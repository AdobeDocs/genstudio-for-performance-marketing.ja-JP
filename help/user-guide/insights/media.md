# メディアの概要

[!DNL Insights] _[!UICONTROL メディア]_ ビューには、選択したアカウントの広告および広告キャンペーンで使用されているメディアのリストが表示されます。 _メディア_&#x200B;は、マーケティング施策での使用が承認された画像、ビデオ、テキスト、その他のクリエイティブコンテンツを表します。

{{connect-insights}}

_[!UICONTROL メディア]_ テーブルは、**[!UICONTROL メディア ID]**&#x200B;を使用して整理されています。 ビューリスト（テーブル）アイコンとギャラリー表示（グリッド）アイコンを使用して、ビューを切り替えることができます。 表の右側にある設定（歯車）アイコンをクリックして、表示可能な列を切り替えます。

![&#x200B; メディアフィルターとテーブル &#x200B;](/help/assets/insights-media-filter.png){zoomable="yes"}

_[!UICONTROL メディア]_ ギャラリービューには、メディアのプレビューとクリックスルー率などの指標のコラージュが表示されます。 ギャラリーの右側にある設定（歯車）アイコンをクリックして、**[!UICONTROL カード設定]**&#x200B;を開き、3つの表示可能な指標のいずれかを切り替えます。

- CPA （アクション単価）
- CTR （クリックスルー率）
- CPC （クリック単価）
- 費用

{{filter-table}}

## メディアの詳細

_メディアの詳細_ ビューで、選択したメディアを使用する広告を確認できます。 詳細には、合計メディアパフォーマンス、メディアを使用した広告、ユーザー定義の属性、メディアに関連するAIが検出した機能などが含まれます。

## メディアパフォーマンス

インサイト指標は、施策の成功に貢献したメディアと、最も効果的なメディア属性を評価するのに役立ちます。

次の表は、[!UICONTROL &#x200B; メディア &#x200B;]のテーブルビューで主要なデジタルマーケティング指標の定義とインサイトを示しています。 各指標には、メディアに関する概要、指標の計算方法、その重要性と影響を把握するための1つ以上のインサイトが含まれています。

| 指標 | 定義 | Insight |
| ---------------------- | ----------------------------- | -------------------------------- |
| **[!UICONTROL メディア ID]** | 画像、ビデオ、テキスト、その他のクリエイティブコンテンツに関連付けられている名前。 | いずれかの主要指標の列見出しをクリックして、テーブルを並べ替えます。 |
| **[!UICONTROL インプレッション]** | インタラクションや表示に関係なく、メディアがチャネルに読み込まれるたびにカウントされます。 | インプレッション数が多い場合、幅広い可視性が示されます。ただし、Adobe insightの真のパフォーマンスを把握するには、他のエンゲージメント指標と比較してインプレッション数を考慮する必要があります。 |
| **[!UICONTROL クリック]** | ユーザーがメディア上でクリック可能な要素（リンクなど）を操作する回数。 | クリック数が多い場合は、コンテンツへの関心とエンゲージメントが高いことを示します。これは、効果的で適切なオーディエンスにリーチできる可能性があります。 |
| **[!UICONTROL CTR &#x200B;]**<br>_クリック率_ | 広告内のメディアクリックにつながったインプレッションの割合（%）。<br>**計算**: `clicks`を`impressions`で割った | クリック率が高い場合、そのメディアがオーディエンスにとって非常に関連性が高く、魅力的であることを示しています。 メッセージとデザインがオーディエンスの興味を効果的に引き、行動を促していることを示唆しています。 さらに、CTRが高い場合、メディアが適切にターゲティングされ、想定したオーディエンスの共感を呼び起こすことを意味する可能性があり、それによりキャンペーン全体のパフォーマンスが向上します。 |
| **[!UICONTROL CPM &#x200B;]**<br>_千件当たりのコスト_ | メディア インプレッションの1000個あたりの平均コスト。<br>**計算**：合計金額`spent`をインプレッション数で割り、1000を掛けた値 | CPMの値が低い場合は、クリックスルー率が高い場合は特に、費用対効果の高いメディアのパフォーマンスを示している可能性があります。 |
| **[!UICONTROL CPA &#x200B;]**<br>_アクションあたりのコスト_ | 購入やサブスクリプションなど、特定の顧客アクションを達成するために費やした平均コスト。<br>**計算**：合計金額`spent`を完了した顧客アクション数で割った値 | 価値のある顧客アクションにつながるメディアを特定するのに役立ちます。 |
| **[!UICONTROL CPC &#x200B;]**<br>_クリックあたりのコスト_ | メディアのクリックごとに関連付けられた平均コスト。<br>**計算**：合計金額`spent`を`clicks`で割った | 特にコンバージョンの増加と比較すると、平均コストが低いことは、広告費がコスト効率に優れていることを示している可能性があります。 |
| **[!UICONTROL 支出]** | 特定の期間に個々のメディアに関連する予算から費やした金額。 | 短期間で多くの費用が発生した場合、迅速な使用を示している可能性があり、リソースの早期枯渇につながる可能性があります。 また、主要なパフォーマンス指標に対して費やした費用を追跡し、全体的な投資収益率を監視できます。 |
| **[!UICONTROL これらの広告で使用]** | このメディアを使用する広告の数。 | |
| **属性** | このメディアに存在する固有の機能のリスト。 | 顧客属性は、オーディエンスの共感を最も惹きつけるクリエイティブ要素を特定するのに役立ちます。 |
