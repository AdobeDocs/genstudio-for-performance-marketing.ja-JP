# Adobe GenStudio for Performance Marketing [!DNL Content]

GenStudio for Performance Marketing [!DNL Content] は、すべてのブランド承認済みアセット、エクスペリエンス、テンプレートを保存、検索、共有するための一元的な場所を提供します。生成 AI を使用して、コンテンツの編集やリミックス、コンテンツの使用状況やセンチメントに関するインサイトの取得、既存アセットの更新や再利用を行うことができます。

## [!DNL Content] の機能

GenStudio for Performance Marketing [!DNL Content] は、承認済みアセットの管理を容易にし、コンテンツライフサイクルを高速化します。**[!UICONTROL [!DNL Content]]** では、パフォーマンスの高いコンテンツを検索、特定、再利用したり、アセットやエクスペリエンスを選択して、エバーグリーンキャンペーン用の新しいバリアントの作成をジャンプスタートしたりできます。

### アセットをアップロード

**[!UICONTROL アセットを追加]**&#x200B;パネルでは、ローカルファイル内のアセットをドラッグ＆ドロップまたは参照できます。オプションで、OneDrive や Dropbox などの外部ソースからアセットを読み込めます。アップロード前に必須となる情報は、[!UICONTROL キャンペーン]名またはプロジェクト名のみです。キーワードなどの詳細情報を指定すると、チームの全員が関連コンテンツをすばやく特定および取得できます。

### 承認済みコンテンツを検索および発見

承認済みアセットを保存する際、[!DNL Content] は豊富なメタデータ、生成コンテキスト、監査履歴を保持します。アセットの詳細は、フィルターや検索文字列を使用して検索結果をすばやく絞り込むのに役立ちます。GenStudio for Performance Marketing の AI は、カラーなどの特定の詳細を自動的に識別および保存します。検索フィールドで `blue` を検索すると、コンテンツリストが「blue」のタグが付いたアセットに絞り込まれます。

### テンプレートを操作

テンプレートを使用すると、作成プロセスが高速化し、複数のチャネルをまたいで一貫性のあるコンテンツを生成できます。レイアウトやデザイン要素が事前設定済みのカスタムテンプレートをアップロードすると、作成プロセスの開始点として使用できます。基本的なテンプレート要素と手順について詳しくは、[テンプレートの操作](../templates/use-templates.md)を参照してください。テンプレートの作成について詳しくは、[テンプレートのカスタマイズ](../templates/customize-template.md)トピックを参照してください。

### 承認済みのエクスペリエンスを翻訳

承認済みのメールや有料メディアのエクスペリエンスは、[!DNL Content] _[!UICONTROL エクスペリエンス]_&#x200B;ギャラリーまたは [!DNL Create] ランディングページから複数の言語に直接翻訳できます。[コンテンツから翻訳](../create/translate-experiences.md#translate-from-content)または[作成から翻訳](../create/translate-experiences.md#translate-from-create)を参照してください。
